# Inventory Management System

A web-based Inventory Management System built using HTML, CSS, and JavaScript that allows users to manage and track inventory items efficiently through a simple and user-friendly interface.

This project demonstrates frontend development, CRUD operations, and basic inventory tracking functionality.

---

## Features

- Add new inventory items
- View inventory list
- Update existing items
- Delete inventory items
- User-friendly interface
- Dynamic inventory updates using JavaScript

---

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)

---


---

## How It Works

The system allows users to:

1. Enter item details
2. Add items to inventory
3. View inventory list
4. Update item information
5. Remove items from inventory

All operations are handled dynamically using JavaScript.
